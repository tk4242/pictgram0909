# `ai/` — 2 つの AI の作業領域

Codex と Claude Code が成果物・調査メモ・下書きを置くディレクトリです。
アプリケーションコード（`app/` など）とは分離してあるので、ここに何を置いても
Rails の動作には影響しません。

ルールの本体は [`AGENTS.md`](../AGENTS.md) §9 を参照してください。

## 構成と所有権

| ディレクトリ | 所有者 | 他方の権限 |
| --- | --- | --- |
| `ai/shared/` | 両方 | **読み書き可** |
| `ai/codex/` | Codex | **読み取りのみ** |
| `ai/claude/` | Claude Code | **読み取りのみ** |

**相手のフォルダのファイルを書き換え・削除してはいけません。**
問題を見つけたら `docs/ai-worklog.md` に指摘として書きます。

## 何を置くか

### `ai/shared/`

両 AI が参照する共通の情報。

- 調査結果・設計メモ（どちらが書いたかを本文冒頭に明記する）
- VPS の構成情報（ディレクトリ構成、サービス名、ログの見方）
- 決定事項の根拠資料
- Claude Code によるレビュー結果（`reviews/`。生成物は Git 管理外）

`ai/shared/` のファイルを更新したら、`docs/ai-worklog.md` にも
「どのファイルを何のために更新したか」を 1 行残してください。

### `ai/codex/` `ai/claude/`

自分の作業の途中経過。相手に読ませたいが、共有物として確定はしていないもの。

- 検証ログ、コマンド出力の控え
- 実装の下書き・比較検討したパターン
- 相手のコードを読んだときの詳細メモ

## 置いてはいけないもの

- **秘密鍵・API キー・パスワード**（`~/.ssh/id_ed25519` の中身を含む）
- 個人情報を含むログ
- 巨大なバイナリ・データダンプ（リポジトリが重くなります）

これらはリポジトリ外の共有フォルダ（`~/Desktop/ai-shared/`）に置いてください。
セットアップは `ai/setup-desktop.sh` を実行します。
